## 1. Why Forget to Foresee wins

- **A live economy on NEAR testnet, not a mock.** 20 scripted trader wallets (`trader-01` … `trader-20.ftf-town.testnet`)
  send real `trade` calls to `ftf-town.testnet`, about **1,500 tx an hour** (09:50–10:50 UTC: 1,523 successful, 0 failed).
- **7,889 successful testnet transactions on 13 Nov by 11:22 UTC, 2 failed** (7,836 market trades, 39 chest openings,
  11 guest accounts, 3 dragon mints; 25 distinct signers). Counted from the public indexer, no keys:
  [docs/proof/tx-24h.md](../proof/tx-24h.md).
- **An independent counter.** `node tools/count/count.mjs --window <day> --write` recounts every game contract's
  transactions from the public NearBlocks v3 indexer; Town Pulse (`/pulse.html`) shows the same count live with explorer
  links. Anyone can rerun it.
- **11 contracts deployed on testnet** (sources in `contracts/`, checks in [docs/near-built-1-14-nov.md](../near-built-1-14-nov.md)):

  | Account | What |
  |---|---|
  | `ftf-seasons.testnet` | season commit-reveal: Merkle root before trial 1, 15 leaves revealed and re-hashed on chain |
  | `ftf-shards.testnet` | NEP-171 memory shards bound to the season's Merkle leaf |
  | `agents.ftf-coordinator.testnet` | agent card NFT (Iris's end-of-season state) |
  | `guests.ftf-coordinator.testnet` | Day-1 guests: a browser key becomes a guest sub-account (46 by 13 Nov) |
  | `heroine.ftf-coordinator.testnet` | Elise NFTs, each token with its own account (`act_as_token`), 46 minted |
  | `companions.ftf-coordinator.testnet` | dragon NFTs owned by a heroine token's account, 6 minted |
  | `ledger.ftf-coordinator.testnet` | agent track records and TEE decisions |
  | `chests.ftf-coordinator.testnet` | loot chests: 10,000-card deck, 1,000 NFT, committed root, TEE-attested seed |
  | `skins.ftf-coordinator.testnet` | wheel grand prize skin (cap 100, one per account) |
  | `ftf-town.testnet` (v4) | silk ledger, stalls, pledges as deeds, the Gate-Loom (`pay_gate`), tournament |
  | `items.ftf-town.testnet` | NEP-245 multi-token town items, five monster resources registered |

- **NEP-245 items** (`items.ftf-town.testnet`): core, metadata, events, minters only, no approvals; the player market's
  rules are one file shared byte for byte by game and relayer.
- **Relayer coordinator pattern.** The browser holds only its own ed25519 key; a guest key moves nothing alone. The
  guest signs a request, the relayer's coordinator key calls a coordinator-only `*_for` method (`pay_gate_for`,
  `pledge_for`, `claim_for`, `invest_stall_for`, `enter_tournament_for`, …) that records the request hash once
  (replay-safe) and enforces limits (40 moves a player a day, 20,000 for everyone). Every server key is a function-call
  key limited to its methods. [docs/town-act.md](../town-act.md), [docs/town-gate.md](../town-gate.md).
- **TEE agents via NEAR AI Cloud.** Townsfolk speech, the trade advisor and the clans' strategy layer come from
  `Qwen/Qwen3-VL-30B-A3B-Instruct` in confidential inference (Intel TDX + GPU attestation). The browser re-checks the
  signature before an answer replaces the scripted line; `node tools/verify-tee/verify.mjs answer.json` prints PASS.
- **Verifiable chests.** The deck root is on chain, the seed is a TEE-attested answer, the contract draws itself;
  `node tools/verify-chest/verify.mjs` checks the deck and every opening.
- **NFTs that own NFTs.** A heroine (Elise) token has its own account, and that account owns the player's dragons,
  e.g. `nacre-cy-8` owned by `elise-cy-8.heroine.ftf-coordinator.testnet`. Holder access reads any testnet account and
  unlocks a perk. Threat model with a test per guard: [docs/nft-threat-model.md](../nft-threat-model.md).
- **Wallet sign-in built** behind the `accountLogin` flag: NEAR wallets through NEAR Connect (HOT, Meteor, Intear,
  MyNearWallet, OKX and more, NEP-413), EVM (EIP-191), Solana (signMessage) and passkeys (WebAuthn P-256 verified by
  the relayer). A login links to the Day-1 guest account; no key on our server. [docs/account-login.md](../account-login.md).
- **Try to cheat it:** https://spacexceo.github.io/forget-to-foresee/cheat.html, six attacks (replay, chest repeat,
  forged expedition log, second free mint, price band, self-trade), each with its guard, error code and test.
- **Judge path:** README "do X, see Y" in 7 steps, each with a public proof link; the same steps in the game with `?judge=1`.
- **Tests green on this commit:** game **1,187 / 1,187**, relayer **137 / 137** (plus server 39, presence 6 and 9 Rust
  contract suites in [docs/STATS.md](../STATS.md)). `bash scripts/verify-all.sh --skip-rust` prints one table.
- **Wallet-free onboarding:** no wallet, no seed phrase, no gas prompt in the normal loop; the free Day-1 mint gives a
  guest account, an Elise NFT and a dragon.

## 5. How to merge (the lead's loop)

```bash
R=<checkout>; G="git -c safe.directory=$R"
$G fetch origin
$G worktree add ../merge sprint/5h && cd ../merge
$G merge --no-ff origin/claude/<branch>          # one branch at a time
```

1. **Conflicts in `game/package.json`** (the test list): keep ours and append their new test files.
2. `cd game && npm test` and `cd relayer && npm test` (both green).
3. Build: `cd game && FTF_BASE=/forget-to-foresee/ npx vite build`.
4. Serve `dist` under `/forget-to-foresee/` and load it headless: no `PAGEERR`, both plain and with `?ff=all`.
5. Push `sprint/5h`, then fast-forward `main`:
   `$G fetch origin main && $G merge-base --is-ancestor origin/main HEAD && $G push origin HEAD:sprint/5h HEAD:main`
   (if the ancestor check fails, merge `origin/main` first and rerun the tests).

Known traps:

- **TDZ boot failure:** a static import from `scenes/` or `play/` into `sprint/` or `market/` breaks the boot
  ("Cannot access … before initialization"). Use `import()`, and list core play modules in `CORE_PLAY` in
  `game/build/chunks.js`.
- **Shared copies:** `relayer/lib/near-tx.js` stays byte-identical to `game/src/net/near-tx.js`; the shared rule copies
  (`market-rules.js`, quest rules) stay synced; tests check the copies.
- **Never commit `node_modules` symlinks** made in a worktree.
- The drive of the owner's checkout is exFAT: run git with `-c safe.directory=<path>`.
- Regenerate numbers before the final merge: `node scripts/stats.mjs --write`.
