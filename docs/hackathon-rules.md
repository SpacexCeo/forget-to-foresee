## Как судят
- Первый слой — AI-скрининг (Claude Code и Codex): запускаемость, проверка заявленных функций. Решают люди (Q-017).
- Значит: точные команды, ожидаемый результат («do X → see Y»), тесты, без секретов в репозитории.

## Треки-кандидаты
- **games** — экономика как часть игрового цикла, не токен ради токена.
- **nfts** — NFT как аккаунт/актив с поведением.
- social — коллективное владение и общий бюджет (если кланы-совладельцы войдут в MVP).

## Правила работы в репозитории
- Маленькие коммиты с понятными сообщениями после каждого законченного шага; пуш сразу после коммита.
- Никаких ключей и секретов: только `.env.example`.
- Ничего не заявлять в README, что не запускается.
