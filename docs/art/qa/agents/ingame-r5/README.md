# Round-5 agents in the game, real WebGL

Iris on the island (`?demo=judge&play=direct&mode=walk`, HUD hidden) at three camera distances, built
from ccf610b and rendered by Chromium on ANGLE/Vulkan on an RTX 4090 (`UNMASKED_RENDERER`: NVIDIA
GeForce RTX 4090, Vulkan). No console errors. A first run showed a black rectangle in the top-left
of the close shot that did not come back on the rerun (a one-off capture glitch, not in the game's DOM).
The figure reads well at mid and close range; the new hands are too small to read from the default
camera, which is expected.
