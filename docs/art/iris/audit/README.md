# Iris audit, 10.11.2026 (I-001 step 1)

What was audited: the Iris build rebuilt on the GPU server from the sources of `claude/iris-final` at its start
(same as `claude/town-v1`, "Iris v13"). The rebuild matches the shipped `game/public/assets/models/agent_iris.glb`:
the same 22 meshes, triangle counts, 61 bones, 9 clips and texture set; the hair cards differ by 92 welded vertices
of 12,236 and the bakes by compression noise (8,177,912 vs 8,175,560 bytes).

Sheets (Cycles, neutral studio light, `art/agents/iris_hero/qa_audit.py`, -1.4 EV): `audit_turnaround.jpg`,
`audit_turnaround_rear_quarter.jpg`, `audit_face.jpg` (neutral, blink, smile, the understand wink frame; profile and
three-quarters; open mouth, celebrate, defeat, talk), `audit_detail.jpg`, `audit_idle.jpg`, `audit_walk.jpg`,
`audit_run.jpg`, `audit_clips.jpg`. In the game (`qa_ingame.cjs`, the real renderer on software GL, town spawn):
`ingame_town_*.jpg`; `ingame_town_game_camera*.jpg` is the game's own camera, untouched.

Not captured yet: the archipelago screenshots (the software-GL run is slow; they are added when it finishes) and
motion in the game (needs a GPU browser).
