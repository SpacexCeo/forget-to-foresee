## How to verify it yourself

1. Recount: `git clone` this repository and run `node tools/count/count.mjs --window 2026-11-13` (Node 18+, no install, no keys). It pages https://api-testnet.nearblocks.io/v3/accounts/<contract>/txns for 10 contracts and de-duplicates by hash.
2. Spot-check any transaction: open https://testnet.nearblocks.io/txns/<hash>, or ask a node directly: `curl -s https://test.rpc.fastnear.com -H 'Content-Type: application/json' -d '{"jsonrpc":"2.0","id":1,"method":"tx","params":{"tx_hash":"<hash>","sender_account_id":"<signer>","wait_until":"FINAL"}}'`.
3. Compare with the contract's own counter: `trade` in `pulse {}` on ftf-town.testnet (docs/stats-page.md) grows by the trade count above.
4. Browse an account's history: https://testnet.nearblocks.io/address/ftf-town.testnet.
