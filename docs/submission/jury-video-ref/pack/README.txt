AGENTS — LAYERED ANIMATION ASSET PACK

This pack contains individually cropped image elements, derived from an AI-generated matching asset sheet. The six clan cards have their own transparent PNGs, and icons, title, ornaments, character, and environment components are separate.

IMPORTANT LIMITATIONS:
- AI-generated asset sheet is not the original editable 3D scene. Some dark pixels, glow and edge details may be imperfect after transparency extraction.
- Each card is one flattened layer (typography and illustration are not independent inside the card).
- The environment concept plates are matching visual alternatives, not a pixel-exact reconstruction of the uploaded composite image.
- For true 3D camera depth, regenerate overlapping backgrounds and use real game footage and game models.
- For production text/data, typeset as editable text rather than relying on the lettering baked into generated images.

Recommended layer order: background concept, islands, fog/VFX, character, cards, UI ornaments, title.
