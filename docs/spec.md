# Forget to Foresee — ТЗ (рабочая выжимка)

Источник: единое ТЗ владельца от 07.11.2026 (12 разделов + приложения A–G). Полный текст — у владельца. Здесь — обязательные требования, границы и гейты для исполнителя.
Статусы: **[П]** подтверждено автором · **[А]** авторская версия / предложение · **[?]** требует уточнения.

## 0. Рамка
- [П] Название Forget to Foresee, вдохновение «Прибытие» (без копирования логограмм, персонажей, объектов, музыки, сцен), Three.js, формат «Мир + Раковина».
- [П] Механика по журналу — «авторская версия, правила не подтверждены». Эталон — `prototype-2d/index.html`. Не изобретать 12 слотов: логограмма ровно из 4 слотов.
- Старт работ — только после отдельного OK владельца (гейт G0). Реальные платежи, mainnet, деплой контрактов — только с отдельного разрешения.
- Рабочая цель: code freeze 13.11 20:00 (Киев), 14.11 — буфер и подача. Дедлайн 15.11 01:59.

## 1. Вход и онбординг
- [П] Лобби с качественным анимированным фоном (reduced motion → статичный кадр, анимация не блокирует управление).
- [П] Порядок будущего paid-режима: лобби → проверка оплаченного аккаунта (entitlement на сервере) → NEAR-кошелёк (challenge + подпись, NEP-413) → **обучение** → **кастомизация** → первый контакт с миром. Обучение и кастомизацию не менять местами.
- В хакатонном слайсе: **guest/testnet demo** — бесплатный synthetic entitlement, кошелёк только для добровольного testnet-действия, реальные деньги не принимаются, это явно подписано.
- [А] Тайминг первых 20 минут, учебный пример «Раковина II / Дар / 20 / +2».

## 2. Механика (переносится из прототипа без изменений)
- Сезон, язык (4 слота, 4 формы штриха, точки в ядре задают начало чтения), якоря (10 шёлка), память и осколки, фрагменты со скрытым V/tV, напряжение (100 = уход Раковин), кризис тика 13 и Ключ Пепла, двойное кольцо, голосование, биография, Наследник.
- Защита транспорта: actionId идемпотентен, expectedVersion, явная причина отказа, без частичных изменений.
- **R0:** извлечь все константы, действия, RNG, порядок событий в `docs/rules-baseline.md` со ссылками на функции; расхождения журнал↔код↔ТЗ согласовать с автором.
- **Parity:** чистый `engine.js` без DOM/Three/сети/LLM, часы и RNG передаются явно. Fixtures: ≥20 seed × 3 трассы (кооперация, удержание, разрывы) + все типы памяти, тики 12→13→14, напряжение 99→100, ничья, финалы, пустой ресурс, повтор команды. Одинаковые seed+намерения → одинаковое нормализованное состояние в 2D и headless. Расхождение блокирует 3D.
- Перенос в JS без одновременной смены правил; новые модули и контракты — TypeScript.
- `S.fx` — адаптер семантических визуальных событий; камера, skip, FPS не меняют состояние.

## 3. Агенты, голограммы, реплики
- [П] Каждое механическое агентское событие показано в мире: голограмма + жест/движение информации + VFX/SFX + короткая локализованная реплика (speakerId, i18n key, args). Сырой лог — только разработчику.
- Таблица постановок: появление, передача знания, вопрос Гостям, якорь, Дар/Буря/Зов, доверие, обман/разрыв, долг/эскроу, фрагмент в Свитке, отказ.
- Важные сигналы — минимум две формы (силуэт/штрих + текст/звук). Reduced motion, без вспышек, субтитры, контраст, цветонезависимость.
- Частичное знание: NPC знают только наблюдённое. LLM не вычисляет исходы.

## 4. NFT и экономика
- Хакатон: бесплатный guest demo; testnet — проверяемые commitments и (если пройдёт гейт) демо-NFT. Без реальных ставок, платного входа, денежных аукционов и призов.
- Шёлк, V, доля дара — закрытые игровые ресурсы, не NEAR.
- [П] Будущий paid: 1 NEAR базовый доступ, 2 NEAR — тот же доступ + косметика. Равные механики. Только после beta-гейта.
- Mint добровольный, без приватных данных. Запрещено: pay-to-win, lootbox, cash rewards, staking/yield, токен, продажа доверия.

## 5. Визуальное качество
- [П] Насыщенный мир, детальные объекты и интерьеры **с потолками и collision**, каждый осматриваемый объект — индивидуальная проработка и близкий осмотр.
- Остров-диорама: 6 лагерей вокруг Свитка, 4 Раковины над зонами якорей, переходы 30–45 с.
- Внутри Раковины: законченный замкнутый объём (пол, стены, свод), туман не прячет отсутствие геометрии.
- Камера MUST: изометрия 3/4, ограниченные вращение и zoom; WASD или клик по земле, E/тап — контекст; клавиатура для всех решений. Без first-person.
- Collision: kinematic capsule, swept movement, 30 Гц, без туннелирования при низком FPS; камера со sweep без клиппинга.
- Slice-объём: 3 hero-объекта (якорь, стол Свитка, осколок), 6 агентов, 4 Раковины + 1 интерьер, 6 лагерей, остров. Не прошедшее art-QA помечается greybox.

## 6. Редкие события VFX
Сожжение памяти (8 с), видение (10 с), кризис 13 (12 с), двойное кольцо (9 с), коллективный финал (12 с), уход Раковин (10 с). Low tier, reduced motion, skip не пропускает правило или согласие.

## 7. Еженедельные турниры
- [П] Каждую неделю событие-турнир **в том же мире и на том же движке**. Полная production-платформа — после гейтов.
- Слайс MUST: карточка турнира в лобби → synthetic enrollment → ускоренный server-clock fixture → один сезон → безопасная таблица результатов → немонетарный трофей. Помечено как симуляция. Тесты: дубль enrollment, рестарт координатора, reveal до barrier закрыт.

## 8. Конструктор голограмм
- [П] Агент собирается «из чего-то» и перерабатывается фильтрами; игрок регулирует цвет и другие параметры.
- Recipe: shape, components, particles, layers (whitelist), palette, noise, light, trails, gesture → канонический recipeHash. Preview, randomize, reset, save, low-tier профиль. Косметика не влияет на механику.

## 9. Локализация
- [П] Каждая реплика локализована. MUST: русский и английский, смена языка без нового сезона, нет сырых ключей.
- События хранят смысл и ID, клиент рендерит через ICU-плейсхолдеры. Proof-байты и тайные фразы не переводятся.

## 10. Инфраструктура
- [П] Есть 3 сервера и 3 GPU; параметры [?] неизвестны. Без инвентаризации не заявлять CCU.
- Three.js рендерится у игрока; сервер — CPU-задача (rooms, persistence). LLM — через API с шаблонным fallback, не в critical path.
- Perf targets (desktop/mobile): 60/30 FPS, ≤120/65 draw calls, ≤500k/180k треугольников, initial load ≤10/6 MB.

## 11. Раскадровка
16 текстовых keyframes (лобби → доступ → учебная голограмма → четыре сектора → конструктор → первый остров → персонажи → внутри Раковины → осмотр → передача свидетельства → цена памяти → видение/proof → кризис → двойное кольцо → недельное событие → финал). ## Приложения (ключевое)

### A. Архитектура
2D baseline + parity fixtures → чистый детерминированный engine → authoritative room + event log → Three.js + S.fx + i18n → Merkle + testnet verifier → полный сезон.
Логические каталоги: `game/src/game/` (engine, crypto), `game/src/shared/` (TS-схемы), `game/src/render/`, `game/src/scenes/`, `game/src/ui/` + `locales/`, `server/` (rooms, tournaments, persistence, near), `contracts/`, `tests/fixtures/`. Локальный guest-режим может держать engine в браузере с пометкой «локальная демонстрация».

### B. Данные и API
Сущности: Session, Room/Snapshot (per-viewer проекция, секреты не уходят всем), Memory, Relationship, Anchor, Fragment, Shard, DomainEvent, Commitment/Reveal, Order/Entitlement, Tournament/Enrollment/Result. WS `room.command` {actionId, expectedVersion, type, args}; resume по lastSeq. Transport 10 Гц ≠ story tick.

### C. Проверяемость
- Root расписания фиксируется до первого действия. Leaf = domain tag + schemaVersion + seasonId + index + canonicalEvent + соль ≥32 байт CSPRNG. Test vectors, negative tests (подмена event/salt/path/season отвергается).
- «Проверено ончейн» говорим, только если testnet-контракт действительно проверяет proof. Root ончейн + проверка в браузере называется именно так.
- Тайная фраза Пепла — отдельный salted commitment. Видение: eventRoot (неизменное) отдельно от contingent branch (при бездействии).
- Кошелёк: challenge с nonce, NEP-413, без seed phrase. LLM не видит ключей. NFT (NEP-171/177) — optional, после testnet-тестов.

### D. Безопасность и AI
Клиент не меняет шёлк/память напрямую; идемпотентность; нет утечки V/фраз/будущего в bundle и API; prompt injection — LLM без tools/RPC/кошелька, JSON-schema намерений. LLM не нужен для языка, исходов и proof; MUST — детерминированные политики кланов и шаблоны, timeout 3 с → шаблон.

### E. Scope недели
- **MUST:** parity engine; полный сезон Ирис + 5 NPC; остров + интерьер Раковины; 4-слотная логограмма; якоря; цена памяти; осколки; фрагменты; кризис 13; финалы; S.fx; RU/EN; шаблонный AI; локальный proof verifier; минимум одно воспроизводимое **testnet commitment/reveal**; guest/demo onboarding; спроектированный weekly tournament + минимальное помеченное событие; утверждённый hero-scope с inspection QA.
- **SHOULD:** общая комната и 2–4 helper через QR; проверка proof контрактом; добровольный testnet NFT финальной карточки; reconnect, доп. accessibility.
- **LATER:** 6 человеческих кланов, продовые NFT/escrow, галерея, новые сезоны, озвучка, paid onboarding.
- **Вырезано:** фотореализм, open world, бои, live voice AI, свой токен, mainnet-аукционы, реальные призы, MMO.
- **Cut rule:** если к концу D2 нет полного сезона без блокера — отключить helpers, NFT mint, LLM, сложный туман; оставить остров, Раковину, 4 сектора, память, proof, исходы. Если testnet недоступен — продукт и видео маркируются как local cryptographic demo.
- Roadmap: D0 (7.11) baseline + fixtures + skeleton; D1 parity + renderer; D2–3 полный greybox-сезон, testnet root; D4 режиссура, первый hero, турнир-fixture; D5 QA; D6 (13.11) freeze 20:00; D7 буфер.

### F. Исполнители
Один владелец на каталог/контракт; engine.js и crypto.js — только их владельцы. Критический путь P0 → P1 → P3 → P7, параллельно art (P10). Сетевые helpers, NFT и LLM не блокируют сольный сезон.

### G. Приёмка (выборка)
Parity 2D↔headless; повтор команды не удваивает расход; отмена до сожжения памяти; нет утечки секретов в сети; verifier отвергает подмену; видение vs вмешательство маркировано; кризис 12→13 по baseline; смена языка посреди сезона; весь сезон без LLM; skip/quality tier не меняют состояние; выход helper без softlock; wallet без подписи ≠ identity; weekly job идемпотентен при рестарте; интерьер без дыр и проваливания на 10–15 FPS; recipe стабилен после save→reload→low→reset.
Гейты: G0 OK владельца → G1 headless parity + сольный loop → G2 testnet slice → G3 social/weekly beta → G4 реальные деньги/NFT.
