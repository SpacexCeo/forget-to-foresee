## README first-screen checklist (what fits above the fold on a 1080p GitHub page)
1. One-line logline and the track(s).
2. Live link ("Play in browser, no wallet needed") and the video link, both in the first ten lines.
3. A GIF or screenshot of the signature moment (forget a memory, see the future, verify the reveal).
4. Real/mock status in one sentence ("contract tested, not deployed" or the NearBlocks link).
5. Quick start in 3 to 7 commands with expected output.
Each missing item costs C6 half a point; items 2 and 4 missing also feed the five-minute first pass (section 5,
step 0).
